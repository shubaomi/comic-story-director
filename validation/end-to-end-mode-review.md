# R13协作模式静态走查
2026-10-08。证据：文档审阅与下述情境推演；不是独立代理执行或真实读者测试。

| 输入情境 | 预期与走查结论 |
|---|---|
| “一次性完成整部故事及插画，只给我最后审阅” | 记录end_to_end；先完整生产合同，再设定/试画/逐页检查，内部通过直接推进；最终final_review。入口/流程/批准/视觉规则一致。 |
| “只帮我从我的喜好审一遍” | 不授权改稿或绘图，不推断完整委托。 |
| “先写大纲，不出图” | staged文字范围有效，不受其他作品的整部委托影响。 |
| “一次性完成文字稿” | 仅文字，不能生成参考图。 |
| 明示10次上限，第10次后仍有缺陷 | 不超用户硬上限；不把缺陷标完成。自设保护线与用户上限分开。 |
| 工具unknown或限额失败 | 核查结果/保存状态，停止相依调用；其他可完成工作继续，不盲重试。 |
| 用户发“这版孩子不像，请改” | 定向修复并全套检查同类身份问题；不重新询问已授权修复。 |
| 同一故事跨轮恢复 | 核对整部委托和实际文件继续，不因阶段变化重复问授权。 |
| 主角仍有一格六扣/三条腿 | 实际放大检查并修复，生成成功或缩略图不构成通过。 |
| 最终图片齐全、助手审过 | 交付final_review，不自动用户验收complete。 |

R13未改变外部发布、敏感素材、工具权限与真实用户预算边界。个人档案保持.local忽略，不进入公开Skill。
