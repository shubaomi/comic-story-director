- 本次有效批准 ID 与剩余额度：

## 提交给工具的完整提示词

```text
用途：连续漫画 / 设定图；具体作品和资产 ID。
目标：本页必须完成的已批准情节或本次局部编辑。
输入图说明：按实际输入编号说明每张图的实体、用途和不可变特征。
画面与画风：批准的媒介、色彩、光线、比例、画幅和布局。
逐格内容：按阅读顺序列出格号、人物/道具、动作、镜头、关系和情绪。
文字：逐字列出对白/旁白、发言者、顺序；无字须明确。
连续性：进入/离开本页状态、固定身份、服装、道具与空间。
编辑时：只改变什么；其余角色、分格、对白和背景必须保留什么。
避免：本作品已批准的禁用项，不新增剧情或角色。
```

生成时用实际内容替换上面的说明句。保留最终实际提交版本；事后优化提示词不能覆盖历史输入记录。
