# 生成记录

尚无图像调用。每次调用单独增加记录，含失败与未知结果；不要只保留成功的一次。

## 调用记录字段

- 调用 ID、作品 ID、阶段、时间：
- 资产/页/格与版本：
- 批准 ID、生成前剩余额度：
- 工具名称、操作、工具实际披露的模型信息：
- 实际提示词文件与版本：
- 实际发送的参考输入（路径/图像标识、实体 ID、版本、用途）：
- 状态：planned / running / succeeded / failed / unknown
- 可核对的工具返回/调用标识：
- 实际输出位置、格式、是否已归档及打开检查：
- 新文件路径及被修订的旧版本：
- 检测到的问题与审核记录 ID：
- 审核状态：pending / changes_requested / passed
- 用户视觉批准来源：无（真实取得后填写）
- 初始/修复尝试累计次数、费用（未披露写未知）：
- 下一步与停止原因：

输出未返回时不能填写成功文件。unknown 先占一次额度，核对已有输出或与用户说明后再决定是否重新生成。通过审核不等于用户已批准该形象或整篇作品。
