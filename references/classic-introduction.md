# 经典启蒙：按需用途参考

仅在用户明确选择“经典启蒙”用途时读取和执行。用途与原创／改编／续写等创作类型分别写入brief；使用同一W1–W8、实体/场景、分镜、视觉、生成、审核和批准记录。不新建教学工作流，不新增外部服务或部署依赖。单纯讲经典、童话续写或儿童故事不触发本用途。

## 定位和每篇目标

目标场景是小学低年级亲子共读：孩子是主要读者，父母是购买者和陪读者。1–3年级、约6–9岁只是初步讨论参考；每个作品确认具体年级、识字水平、独立阅读能力及阅读方式，不能以年龄替代能力。独立读或家长讲读也须明确选择。不是所有经典或篇章都适合低龄儿童。

每篇只有一个可解释、可检查的理解目标L01，例如能用自己的话说明角色为何作出某个选择，或辨认一个容易混淆的意思。是否理解只能通过之后的实际试读观察；不承诺读完就懂整部经典，不默认考试、打卡或道德评分。父母的购买角色不引入销量预测、运营、收款、上架或销售自动化。

## 在既有阶段落实

- **W1创作定位**：按[简报](../assets/templates/brief.md)记录用途、创作类型、受众、选文及版本、一个理解目标和主要误解。用户已给的信息不重复问；未知写待确认，每轮只问影响下一步的关键缺口。先讨论选文和理解目标并取得方向确认，再深化故事。
- **W2故事定案**：在[source-notes](../assets/templates/source-notes.md)核对原文和解释，提出有结局的情节，大纲B编号对应L01。经典启蒙＋原创生活故事也必须核对所解释概念，不能因为剧情原创就免去来源。新增角色/事件/对白记N；改编保留关键原意并列出偏离边界。用户确认具体故事与选定解释，不把这一步扩大为分镜/出图批准。
- **W3完整剧本**：写完整对白与页格，把映射补齐到P/F编号。在分镜现有“情绪和叙事作用”或页目的处引用映射ID、L01及必要F/I/N编号（仅编辑元数据，不印在画面）。真正可见的经典原文、儿童化释义、原创对白分别标清，不能让人物虚构台词伪装成原典引语。
- **W4–W7**：沿用批准和视觉生成流程，不放宽任何前置要求。按本作约定的文字负担、拼音范围及正文/家长材料区分排版；仅工具实际输出并查看过才算图像证据。新增拼音、说明页或页数变化要说明影响并确认，不能偷加生成额度。现有工具不承诺独立可编辑字层；拼音也要逐字、逐音核验。
- **W8验收**：沿用全篇实际检查和用户最终接受；额外复核目标映射、解释边界、阅读负担与家长材料。格式正确、助手审核通过或父母接受，不等于孩子实际理解。没有试读就写未验证，不能报告教学或治疗效果。

## 原文、解释与新编情节的单一记录

source-notes是来源与解释的事实来源；brief只保留选文摘要、L01与ID引用，outline记录故事因果，storyboard保存实际页格文案，review保存检查结果，approvals保存用户决定。不另建一套重复来源表，也不复制多份互相矛盾的释义。

1. **F原文与事实**：保留用于解释的原文句段、篇章位置、所据版本及可定位出处。古代原文、现代译注和插画分开记录使用权限；原文古老不等于某现代译注或插画可公开使用。未知权限标未知，不默认获授权，也不把权限未知等同于历史文本不存在。
2. **I解释**：区分字面解释、已有注释观点和为了儿童理解所选的表达。每项写依据，已有注释注明作者/版本/位置；自拟白话不伪装成现成译文或经典作者的原意。重要分歧并列记录其依据、差异、对目标的影响和本作取舍。可选一个有依据且适龄的解释，向用户说明并确认；不能包装为唯一答案。若争议使核心目标无法成立，缩小目标或换篇。
3. **N新创作**：人物、情节、道具、对白哪些是本次创作必须可追溯。可用现代生活情境说明一个意思，但不暗示原典发生了这段故事或作者说过这些台词。
4. **映射**：使用source-notes模板的“原文句段F → 释义依据I → L01 → B/N → P/F”链。W2未知页格写待定位；W3提交确认前补齐相关页格。L01只有一个，可由多个页格共同承载。修订释义或目标时按既有依赖规则检查受影响的大纲、对白、图片和批准，不整体撤销不相关确认。
5. **不足与适龄冲突**：找不到版本或出处时标待核实，只讨论有标签的假设方向；不能编造书页、注家或引文，也不能让用户的泛泛认可把未知来源变成已核实。温柔、励志或便于说教都不能成为改原意的理由。若原意不适龄，提出换篇、缩小范围或明确改编边界；不抹去核心含义后仍称忠实改编。

## 用情节解释，区分两类读者

从孩子可理解的生活情境起笔：角色遇到问题、误解或犹豫，作出选择并经历可理解的后果。不要用大段训诫替代冲突与行动；也不必每次由父母、老师或智者宣布标准答案。角色不必完美，不能用羞辱或恐吓迫使服从。

回到所选原文和释义检查结论，不把经典固定简化为“必须听话”“不能表达不满”“不能有追求”。审核性别、家庭、贫富等刻板印象，避免把某类孩子视为天然错误。允许人物表达需要、求助、拒绝和不同看法；这不授权为了迎合偏好而篡改原意。

按brief逐作品商定抽象词、人物数量、单页字量、篇幅/阅读时间和拼音需要。助手先逐页统计实际文字负担、指出难词与跳步，再在试画时核对实际字体、气泡和拼音。不能把一个字数上限当作所有低年级儿童的标准，也不宣称模型估计等同于实测阅读时间。

儿童正文保持可独立跟随的故事；家长的简短解释、出处与陪读提示放在分镜内明确区分的附注区域或独立文字材料，不挤进角色口中。默认先写入现有storyboard的“家长阅读材料”节，并在brief注明是否需要及交付形式；若要额外图片页须另确认页数和额度。需要讨论问题时提供开放式问题，联系生活、允许有依据的不同回答，不附强制标准答案或道德评分。

## 在现有review中追加的检查

- L01是否足够具体且只有一个；页格能否表达它，是否把整部经典的理解压到一篇？
- 每条关键解释能否回到版本/原文/依据，F/I/N是否混同？新编对白是否误标成引文？重要争议、来源缺口是否公开呈现？
- 有没有为催泪、温柔或励志删掉必留含义？若不适龄，是否已说明替代选文/范围及其取舍？
- 正文是否通过可见选择和后果推进；抽象词、人物数、字量、拼音是否符合本作已确认要求？
- 儿童正文与家长材料是否区分；附加材料是否偷偷改变页数、挤占故事或扩大出图授权？
- 是否出现恐吓、羞辱、刻板印象、强制服从、疗效或教学功效夸大？

阻断、待核实和偏好建议仍用既有review分类。简版审阅卡展示所选句段/解释的准确摘要、L01、关键边界与代表页格；不让家长为确认而通读冗长释义，也不隐去会改变决定的争议。文字测试通过只证明流程材料一致；儿童理解和亲子阅读体验留到获授权的实际试读检验。
