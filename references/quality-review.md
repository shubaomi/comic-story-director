# 质量审核与完成标准

逐项执行[成品叙事可理解性检查](narrative-clarity.md)，单独报告叙事、视觉和技术结论。文字准确及画面一致不等于故事讲清楚。

同时执行[协作模式中的既有经验与全篇门](collaboration-modes.md)。end_to_end的自动审阅包括可重复文件/结构检查和助手逐页多模态目视审查；用户审美验收仍独立。记录每项证据，工具不可用写真实限制，不把单页通过扩大为全书通过。

每次审核记录证据层级：文字审阅、静态结构检查、实际查看图像、用户批准。自检只能报告观察结果与建议，不能替代用户对身份和审美的决定。使用 [审核模板](../assets/templates/review.md)。

采用 [标准流程](workflow.md) 的分工：助手完成全量检查，详细证据留在review，用户默认看 [简版审阅卡](../assets/templates/decision-card.md)。按用户取向审阅时，逐条引用其已知偏好与具体页格，给出保留/修改/待决结论，不以人格类型推定“用户一定喜欢”。审阅请求默认不修改源稿，也不把推荐通过标记为用户批准。

## 剧本进入视觉阶段前

仅当brief明确选择经典启蒙用途时，叠加[经典启蒙的审核要点](classic-introduction.md)；普通作品和缺新增字段的旧稿不加载该用途的额外要求。

- 主角的目标、阻碍、选择与结局形成因果链；转折有铺垫，关键伏笔有兑现位置。
- 角色变化来自具体经历，不靠结尾旁白宣布；情绪转变有足够过程。
- 改编/续写的关键事实有选定版本证据，解释和新增创作标记清楚。
- 全部目标页与格都有唯一 ID；对白、旁白、发言者、动作、镜头、实体引用和情节点齐全。
- 页间时间、空间、角色知识与道具状态可以接上；换装、成长、受伤等变化已安排。
- 每页服务故事；不为了控制成本跳过必要剧情。篇幅变更先与用户商议。
- 如有主编创作档案，核对 brief 引用版本与具体情节取舍；区分自述和编辑推导，不以人格标签代替人物逻辑，不复制私人经历或让所有角色成为作者替身。个人取向不得绕过本作已确认的边界或出图批准。

## 每张设定图和页面的实际检查

| 项目 | 检查内容 |
|---|---|
| 身份 | 与批准设定对照：轮廓、比例、肤色/羽色/叶形/把手、标志物、服饰；多角色是否互换特征 |
| 动作与关系 | 动作是否实现分镜意图；站位、朝向、左右手/道具归属、视线和空间关系是否清楚 |
| 场景与时间 | 固定物位置、出入口、光线、天气、时间推进是否符合场景规则 |
| 叙事 | 有无缺格、合并格、跳步、新增角色或事件；高潮与结局是否看得出来 |
| 文字 | 所有对白/旁白逐字核对，无错字、漏字、错误发言者；气泡阅读顺序和遮挡合理 |
| 页面 | 阅读顺序、分格边界、裁切、字量和实际可读性；缩小看节奏，放大看细节 |
| 情感 | 画面是否表达批准的关系与情绪，是否意外引入惊吓、羞辱或说教 |

发现身份、漏情节、错对白等实质问题记为 blocker，必须修复并复查；不确定细节写 uncertain 并请求针对性判断。偏好建议记为 suggestion，不把自己的审美直接当成用户禁令。用户更改要求时先记录新标准及受影响批准，再验收，不能静默降低标准。

如果可访问图像但当前工具无法可靠读出小字，报告文字未核验，不能仅凭提示词宣布字体正确。缺乏图像查看能力时不能给视觉通过结论。

## 全篇完成检查

1. 从第一页到最后一页按清单实际查看；对照分镜核对所有页/格及结局。文件数量正确并不代表内容齐全。
2. 跨页对照主要实体、道具移动、场景方向和角色知识；检查上一页接下一页是否有缺口。
3. 核对重要铺垫与回收是否可见，结局是否兑现起初问题；轻悬疑的谜底是否公平。
4. 核对所有最终页的有效批准版本、参考版本与实际文件，去掉清单里的废弃候选但保留历史文件。
5. 所有阻断问题已关闭，未知结果已处理，最终文件能打开并已归档；向用户展示整套结果与剩余非阻断建议。
6. 用户明确接受该套最终页后，才把作品标记 complete。记录验收对象、消息来源和交付清单。用户还没看时为 final_review。

## 交付与暂停报告

交付说明页数/格数、最后采用的文件路径、完整脚本、参考图、提示词/生成记录和用户验收状态。向用户链接文件时使用实际绝对路径。

暂停报告要说明：哪些产物已完成、什么没有验证、当前阻碍、已用/剩余额度、继续所需最小动作。没有完成的页面不能用占位图代替，失败或待修页面不能标记通过。
