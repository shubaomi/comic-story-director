# 故事开发

本文件的“先确认结局/大纲再展开镜头”：staged由用户确认；end_to_end由助手按[整部委托](collaboration-modes.md)全文审查后冻结，再展开全篇分镜。质量依赖不变，不为每个文字版本停下请示。

## 沟通的单位是故事决策

先从用户已给信息填 [简报](../assets/templates/brief.md)。通常先讨论创作模式、读者和想留下的感受；随后确定篇幅、形式及禁用内容。若用户已有明确方向，直接深化；只有方向尚未定时给 2–3 个在冲突、人物选择或结局上实质不同的提案，并解释收益与代价。

分别记录以下维度，避免把安徒生、悬疑、水彩混成一个“风格”：

| 维度 | 可选示例 |
|---|---|
| 创作方式 | 原创、忠实改编、正统续写、外传、补完、平行世界 |
| 用途（独立于创作方式） | 按作品记录；只有明确选择经典启蒙时加载其专用要求，普通作品或旧稿缺此字段不受影响 |
| 文化或故事来源 | 安徒生童话/丹麦文学童话、北欧民间故事、中国神话/民间童话/古代寓言、格林童话、伊索寓言、希腊罗马神话、凯尔特或斯拉夫传说、《一千零一夜》、日本民间故事 |
| 叙事类型 | 日常、成长、冒险、寓言、轻悬疑、奇幻、无字漫画 |
| 情绪 | 温柔、忧伤、幽默、希望；另记冲突与惊吓程度 |
| 视觉方向 | 水彩、水墨淡彩、工笔、剪纸/皮影、木刻、清晰线描、黑白漫画、手绘绘本、黏土质感 |
| 阅读形式 | 儿童亲子、青少年或成人；页漫/长条、语言、方向、字量和篇幅 |

这些是选择词汇，不是已获授权的文本或插画素材库。不要按文化标签混用服饰、神话人物和故事逻辑；需要具体考据时查明来源并注明不确定处。

## 原创与所有模式共用的编辑流程

1. **方向**：一句话提案、主角的外在目标与内在需要、核心阻碍、结局方向。询问用户真正想保留什么，先选方向。
2. **实体与世界**：写 [实体档案](../assets/templates/entities.md)，将人、动物、植物、物件统一赋予稳定 ID。叙事功能、行为边界、关系、外形不变量与允许变化分开；场景、道具也有 ID。
3. **完整大纲**：用 [大纲模板](../assets/templates/outline.md) 展示开端、发展、转折、高潮、结局；每个关键选择有动机和结果。先确认完整结局再展开全部镜头。
4. **故事检查**：困境通过此前建立的能力、关系或选择解决；没有突然出现的万能道具。希望可以是小而真实的行动，不必大团圆。
5. **全篇分镜**：大纲批准后，按 [分镜模板](../assets/templates/storyboard.md) 写完全部页面。每格尽量一个主要动作，明确角色、景别、空间关系、对白发言者、阅读顺序和状态变化。
6. **分镜检查与确认**：逐条把大纲情节点和伏笔映射到页/格。对白按指定读者可读、放得下；过密时建议拆格或调页，并说明是否改变已批准篇幅，不能静默删情节。

无字漫画在文字字段显式写“无”，不能把遗漏对白误当无字设计。长条也需稳定段落/格 ID，若原定交付页图则修改交付形式需要用户确认。

## 经典改编与续写的前置工作

使用 [原作记录](../assets/templates/source-notes.md)。确认作品、作者、版本/译者、可访问来源、续写时间点以及允许偏离的边界。有多个版本时让用户选定或明确采用哪些版本；不拼接成不存在的唯一正典。

对关键设定分别记录：

- F（fact）：已核对原作事实，附原文位置或可定位证据；未核对时明确标记待核对。
- I（interpretation）：对动机、象征或空白的解释，不写成作者原意。
- N（new）：本次新增角色、事件和世界规则。

没有原文可读时可以讨论标记为假设的续写方向，但不能宣布忠于某版本，不能批准依赖未知事实的正式剧本。已知文化常识不能替代特定版本核对。资料不可访问时说明缺口，向用户请求相关文本或授权使用的版本。

核对原作结束时人物身份、关系、知识、所在地点和未完事件，避免“失忆式”续写。续写需要新的目标与选择，不是机械重复原作受难/获救。偏离原作可作为平行世界或改编续写，须在简报中获用户认可。

使用具体来源前核实其可用范围。古老故事、某个译本与现代插图分别记录来源/许可状态；本包不预先断言任何现代版本可公开复用。公开发行时另核实具体素材，勿把本包的许可证替代作品素材授权。

## 温柔叙事和轻悬疑

以角色互相等待、倾听、递出具体帮助、尊重拒绝来表达爱。允许难过、休息和反复；不要用“你想开就好了”或“变优秀才配被爱”解决冲突。避免以强迫原谅、忍受伤害或无条件自我牺牲制造圆满。

教育意义留在选择的后果和读者的体会中，不额外加长篇训诫。用户要情绪支持时询问作品的内容边界即可，不要求诊断或创伤经历。心理状态属于叙事，不提供治疗保证。

轻悬疑先确定谜底，再安排可见线索、合理误导和回收。每条线索记录何时对读者和角色可见；结尾不能靠未展示的信息反转。惊吓、危险和悲伤程度服从用户简报。

## 转交视觉阶段

提交角色/场景文字档案、完整大纲与全篇分镜的具体版本，汇总未决问题。关键问题未解决时继续文字编辑。用户批准后再进入 [视觉生成流程](visual-generation.md)；“大纲不错”不会使完整分镜或图片生成自动获批。
