# 审阅校准与定稿边界

本页补充[质量审核](quality-review.md)的判定依据，不新增一轮审阅，不改变已有创作合同、授权或各媒介质量门。目标是稳定达到本阶段约定的质量，并能说明证据和剩余局限；不承诺“近乎完美”、永无漏检，也不以不断发现新问题证明审核认真。

## 判定先于修改

- **标准固定到当前作品和版本。** 沿用已确认的受众、文风、来源与交付要求。没有依据的新偏好先作为建议，不在终审中暗自升级为发布门槛。已有合格片段可作为文风参照，不要求各篇复制同一种结构、句长或结局。
- **必须修的问题要能指认。** 至少给出位置、原稿证据、违反的已确认要求或叙事关系、对理解的影响和最小修法。若因关键交代不存在而无法引用，指出前后两个位置及缺失的连接。不能只写“幼稚”“不高级”“不够中国风”便重写；难以判断时标为待核实，先补证据。
- **文学意见也能有依据。** 动机跳变、连续段落同义复述、无法辨明施事者等可结合上下文判定；它们不能因为无法用程序测量就一律降为偏好。反之，符合既定文风且不妨碍理解的倒装、短句、留白或生活细节，不因命中词表而自动删除。
- **必要交代与解释堆积一起看。** 正文应交代足以跟住人物选择、动作和后果的信息；篇末思想说明不能补正文的因果洞。补写后再看是否重复、是否损伤趣味与余味，不以字数增加或古文引用数量证明变好。
- **修订必须有净收益。** 对照改前与改后的完整场景，确认解决原问题且未损失人物差异、奇幻规则、幽默或后续铺垫。没有可说明的收益便保留原文；等效措辞和审美替代列为可选建议，默认不动冻结稿。

保留本Skill既有取向：自然中文；独立短篇与故事群的联系兼顾；思想通过选择、行动和后果体现；心理常识只辅助人物可信度；原典、古注、现代解释和新创作分开。不用通用工程规则替代这些创作判断，也不把某个项目的年龄或素材设置推广给所有作品。

## 证据与结论对应

在既有审阅记录中绑定实际文件路径、版本或哈希、检查范围、方法、结果与未知项即可，不另造重复台账。

- 文件数量、结构、链接、文字比对只能支持对应事实；内容通读、画面目视、实际朗读和真实读者反馈各有不同覆盖。程序全绿、模型高分或摘要完整都不能证明文学质量、儿童理解或用户喜欢。
- 已有证据与当前对象、依赖和条件仍一致时可以沿用，注明原检查时间和范围。修改使哪项结论失效，就重查该项及受影响的前后文、关联篇和输出；不因换轮对话重跑全部检查。线上可用性等会变化的状态须按本次交付重新核对，不能用旧观察冒充当前状态。
- 尚未试读如实记未知，不用“成年人觉得有深意”代替孩子跟住事件的证据。正常亲子交流与必须大量补讲正文外信息分开记录。单个阅读困难值得定位核查，但不能据此宣称所有儿童都不理解。

## 停止和重新开稿

约定范围已实际审阅、已知阻断及明确影响理解的问题关闭、修订影响已复核、交付版本一致，便结束本轮修订并报告本阶段结果。未完成的必需检查是缺口，不能为了收尾降级；不在本阶段范围内的试读或制作不伪称完成，也不擅自追加为前置任务。

编辑审阅完成、交付文件核验、用户接受和实际发布分别记录。已有有效的执行或发布授权继续有效；不用此规则制造重复确认，也不把受托自审写成用户亲自读过并接受。剩余等效润色不阻止提交用户审阅，分数和固定审阅轮数都不是通行证。

冻结后仅因以下证据重新打开相应范围：新发现的具体错误；能定位到段落的读者理解障碍；来源纠正；用户改变目标；版本或导出不一致。系统性问题可以扩大检查，但须说明共同机制及影响范围。用户再次要求检查时照做，并允许结论为“本次未发现需修问题”；没有新证据不自动改写，不能声称今后绝不会发现问题。

## 判例：用于校准，不增加必跑流程

| 情况 | 应有判断 |
|---|---|
| 道具前场交给甲，后场乙无交接便使用，且无魔法规则解释 | 具体连续性缺陷；补必要连接并复核相关场景，不因此重写全书 |
| 用两个近义词均自然、含义一致，仅审核者更喜欢其中一个 | 可选润色；保留原稿，不阻断定稿 |
| 家长须替正文补出关键行动原因，孩子才能跟上 | 定位正文与反馈，判断是否缺交代；不要求孩子背哲学结论，也不直接推广为年龄不适合 |
| PDF可打开、文字比对一致 | 只证明相应文件事实；未看版面、未试读的结论继续保留 |
| 内容和依赖未变，上轮有效证据仍覆盖 | 复用证据；不因新一轮对话强制全量重审 |
| 已冻结后要求换受众、提高思想难度 | 记录为范围变化，按现有授权与变更规则处理，不伪装为旧稿质量缺陷 |
