# 关联童话集的发布收尾与批量修订

用于已有合集的整套编辑与发布委托，承接[按原典类型改编](adaptation-by-source-type.md)及[语言与叙述完整性](prose-quality.md)。本规则不授权发布、不规定每篇字数或图数，也不将普通插画阅读版变成连续漫画、互动童话或视频。

## 固定交付合同

- 先锁定实际作品目录、稳定篇ID、当前正文及来源、图像、合订稿、PDF、网站入口。新稿与旧PDF冲突时，按最近有效编辑决定确认正文，不用时间戳或网站旧稿覆盖已审新稿。清点全部篇目和未完成状态，不以抽读或摘要代替全量审阅。
- 明确已授权的文字与图像修订、源skill与安装副本同步、Git和部署边界。整部委托内自主完成中间编辑决定、自审与必要修复；不逐章重复请示，不把助手选择写成用户逐字或逐图批准。
- 分册推进，每篇保存实际问题、处理或具体保留理由、原典落点、图文绑定与复核证据。逐篇审完后再做整册连续阅读，核前后状态、主题重复、角色关系及取材覆盖；未完成册不能借已完成样章获得验收状态。

## 完整丰富与忠实分别检查

- 故事正文先独立讲清场景、任务缘由、人物所知所感、动作与回应、选择后果和转场。不能靠篇后讲解补齐关键情节，也不能用图画替代正文未交代的事实。保留生活质感、幽默和奇幻，不以机械扩字证明丰富。
- 正文另作饱满度验收：让读者经历重要的犹豫、尝试、环境感受与关系变化，不能把“无明显逻辑错误”当作成品质感已经通过。参照已认可样篇的叙事清楚与生活细节，不套其篇幅。逐篇记具体补写或保留依据；正文、附读和图像改动分别报告，不以附读字数或PDF页数替代正文品质证据。
- 读者说明讲清本篇实际经历、原典所在篇章及必要上下文、原句含义与故事如何取材。原典、古注、现代释读及新创作在自然讲解中分清，不强加“编者释读”“取材边界”等统一栏目；仍须实质说明新增机制和未承载部分。
- 神话物象可以让人认识异物及古人的想象，不必硬套伦理训诫；思想论说须让关键关系参与故事因果。经典全文覆盖按实际已读与承载范围如实记，不以篇数、物件露面或书名相同证明覆盖。
- 简短中心概括和生活尝试须贴合本篇，可提问、观察或小行动，不强求统一训练。神话功效不能作为现实实验，古代医理不能冒充现代治疗建议，不把效果写成教育或疗效承诺。
- 读者页保留经典名称、篇章和必要版本区分；外站核对链接、访问日期、修订号放内部来源记录。站内“原文”须标明实际收录单元，完整收录该单元，不以节选假称全书。公共领域原典与现代整理、注译、图像等权利分别记录，不因古籍年代久远就宣称所有素材均可商用。

## 文字改变后的插画

- 每幅沿实际新正文检查人物身份、时间天气、空间方向、道具归属、行动、奇物能力和锚点。先分为保留、移动、替换、必要新增；成立的旧图可以保留，不能为了重构数量全部重生。
- 删除旧情节后，对应图不得继续暗示旧事件；替代文本和移位不能掩盖画面事实错误。原典实体图核明确形貌，未规定的细节记为绘画选择；不偷加会改变典籍意义的能力或道德奖惩。
- 同册人物与画风沿已选实图保持，必要补图各有理解作用。完整记录实际图像检查与生成版本；生成成功、资产数量、哈希一致不能代替目视验收。

## 可发布与停止条件

- 已授权范围逐篇实读、自审和整册连续性复核完成；已知关键因果缺失、原典歪曲、图文矛盾关闭；正文、合订稿、当前PDF及网站一致，才冻结本次正式版。市场付费意愿、亲子理解与用户审美接受不由模型自审代替。
- PDF检查实际文字完整性、图片顺序、字体、目录跳转与渲染页面。生产网站检查实际新版本、正文与图片、当前PDF下载字节及约定访问权限；本地构建或Git推送不能记作上线。保留回滚和历史版本，避免把其他并行作品一并部署。
- 发布后以具体读者反馈、事实错误、使用障碍或目标变化重新开相应范围。等效措辞与无证据的“还能更好”进入后续建议，不重开全书。存在具体系统性缺陷则仍需修复，不能用停止迭代掩盖已知问题。
- 长任务断点保存真实状态、路径、版本及下一动作。正文完成、图像完成、文件验证、生产上线分别标记；不得以部分完成冒充整套最终交付。
- 中途获准校准内容标准时，持久化为稳定需求并标明受影响篇目。既有部署、权限、哈希等证据按原版本保留，新增内容验收单独完成；有实际增补才发布新版本。校准不是无限审稿，具体缺口关闭并完成一次全册复核后冻结。
