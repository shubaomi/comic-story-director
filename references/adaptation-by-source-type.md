# 按原典类型选择改编方式与验收标准

用于经典取材、改编定位、故事自审及跨作品重构。先确定实际取材单元属于什么文本，再选择相应改编方式；不能让所有作品套用“孩子犯错—受到提醒—学会一个道理”。这是编辑工作分类，不是对经典的唯一学术分类，也不代表已经核对各书全文。

## 先分清本篇承载什么

- 分开记录整部原著的关切、实际选段所说的内容、本篇让读者经历的事情。一个选段或一篇童话不能自动代表全书主旨；书名、引文数量和篇章数量不能证明思想覆盖。
- 按实际单元标一个主要类型，必要时加一个次要类型。一本书可以同时有论说、寓言、对话、神话或历史材料；同书不强制一套情节模型，混合材料只加载适用标准。
- 明确本篇主要目标：理解一个思想问题、经历视角转换、体会有条件的判断，或认识神话世界与物象。人物成长和生活启发可以伴随发生，但不能取代已承诺的原典理解目标。
- 原文事实、古注、现代解释、编辑采用的理解和原创情节分别记录。原文未规定的机制、动机和结局可为童话补充，但不得写成古文已有的意思；争议解释说明选择及限度。
- 如果用户希望每篇传达明确的原典思想，而选段主要记物象、地点或传说能力，应说明两者差异，建议调整本篇目标或另选有依据的材料；不能偷偷把“理解思想”降为“借一个名字”，也不能编造原文的道德训诫。

## 分类选择：形式可以多样，核验对象要准确

下列书名仅作选材路由示例；进入创作仍须实际读取所用完整单元及必要上下文。任何类型都保留奇幻、幽默、人物关系与独立成立的故事。

| 主要材料类型与常见作品 | 可用的童话形式 | 类型专属验收与常见误改 |
|---|---|---|
| 神话地理、物象与能力，如《山海经》的山川条目 | 探索、旅行、奇遇；让奇物的形貌、能力及其所在环境产生具体经历 | 核对外形、动作、能力、地理关系与已知限制。奇物应影响主要发现、行动或感受，不能只负责改名、发光或一次救场。不要求每段都有做人道理；不得为教训人物而取消原典能力、临时增加惩罚条件。 |
| 哲理寓言，如《庄子》及其他书中的寓言单元 | 荒诞事件、尺度变化、多方视角、出人意料的解法 | 保留原寓言提出的问题、关键对照与视角变化，核对结局是否反向。不能把有关“无用”的讨论一律改成最终找到赚钱用途，也不把开放问题硬收为唯一标准答案。 |
| 哲理论说，如《道德经》的关系与转化论述 | 有不同选择及真实代价的完整事件；用处境变化体现关系 | 核对概念之间的关系、条件与限度，不能只抓水、柔弱等意象。避免“弱者必胜”“无为就是什么都不做”等绝对化；故事是理解入口，不是哲学命题的普遍证明。 |
| 伦理语录、论辩和问答，如《论语》《孟子》《传习录》的相应单元 | 关系中的两难、学习与行动、承诺及后果；对话服务于事件 | 保留说话对象、问题、适用处境与论证要点，不能都变成“勇敢一点”或“听话”。不以好人立刻获奖证明正确，不将“自己的任何感受”直接等同于良知。 |
| 卦爻、象与时位，如《易经》的相应单元 | 情势变化中的判断、阶段转换、进退与协作 | 分清卦辞、爻辞及传文层次，核对位置、时机、条件和解释依据。意象与思想关联分别记，不把每卦塞成一个美德，不把吉凶改成现实中的精准预测或保证。 |
| 军事与策略论述，如《孙子兵法》 | 有资源、信息、地形和时间约束的冒险、筹划与冲突 | 决策与结果须依赖明确条件，代价和对手能力可信；保留原文军事语境，转为儿童生活场景时注明类比边界。不能靠全知或降智取胜，也不把日常关系写成操纵他人的战场，或把原著一概说成拒绝一切冲突。 |
| 宗教与解脱论述，如《金刚经》的相应单元 | 对执著和自我判断的观察、视角变化及具体关系 | 所选解释须有可核对依据，宗教语境与世俗类比分开。不能把“空”简化为一切无意义，把丢掉物品等同于觉悟，或把情绪好转当作教义已被完整表达。 |
| 古代医学与身体论述，如《黄帝内经》的相应单元 | 观察、照护、人与环境相处的文化童话 | 分清古代理论、故事比喻与现代健康事实；寓言不能充当生理或疗效证据。不得从古文直接生成儿童诊疗、饮食或用药实践；现代健康建议另行核实。不能宣称一个生活习惯已概括整套医学理论。 |

遇到未列出的材料，先按其实际功能补一项局部标准，不硬塞最近的类别。分类不改变受众、媒体形态、发布权限或已确认故事设定。

## 写作前的一张对应卡

在作品既有取材或审阅记录中保留以下五项，不另建重复账本，也不放入读者正文：

1. **材料**：实际读过的完整原文单元、定位、版本、上下文与未核对范围；正文和注释分开。
2. **类型与目标**：主要类型、本篇要帮助理解或认识的一件具体事情；采用的解释及分歧。
3. **不可改与可创作**：需守住的关系、形貌或条件，以及新增的角色、机制与情节。
4. **事件对应**：哪一段关键经历承载哪一项原典内容，主人公为何行动，结果怎样产生；附注不能替正文补因果。
5. **限度与检查**：本篇未承载什么，按哪条类型标准验收，尚有什么证据缺口。

## 自审：联系存在，还要检查是否抓住中心

- **先看中心，再看对应。** 分别用一句话概括故事的主要冲突／发现和原典选段的内容；即使某件原典物品参与了行动，也要检查它是否只是附属工具。若主线仍是一则通用生活训诫，原典只在途中帮一次忙，不能据此宣布已形成紧密的中心联系。优先调整主要经历或如实收窄承载声明，而不是继续加长篇后解释。
- **替换测试是诊断，不是唯一门槛。** 哲理篇检查换成另一条通用格言后是否仍毫无区别；神话篇检查把奇物换成普通物件后，核心的发现、体验或世界关系是否仍基本不变。现实中有别的工具也能解决同一任务，不自动判失败；关键是本篇有没有真正写出原典独有的体验。不能为了通过测试削弱同伴、制造低级失误或增加无依据的魔法限制。
- **关联方式如实命名。** 可记录为议题转化、寓言重构、物象与能力叙事、有限类比、意象借用或未承载。这些是不同关系，不是神话低于哲学的等级；“意象借用”不能计入思想已覆盖，也不能用改标签掩盖与已确认目标的冲突。
- **共同底线不降低。** 正文独立可懂、人物行为可信、动作因果完整、奇幻规则稳定、语言自然、结局有准备。心理学只用于人物行为合理性，不给每篇强加心理教育任务；仍执行[语言与叙述完整性复核](prose-quality.md)和[质量审核](quality-review.md)。
- **读者说明随类型变化。** 神话篇可围绕“认识什么奇物、古人怎样想象世界、故事怎样展开”；论说篇围绕“原文讨论什么、选择与后果怎样帮助理解”。保留读者能定位的作品及篇章，内部来源证据与权限记录另存。标题、字数和模块不机械统一；原创生活启发不能标成原文本义。
- **生活实践有依据、有边界。** 已约定的小问题应直接关联本篇：可观察、画出差别、换个角度想，或试一个安全的小行动；不必都是纠错或做人任务，不强制每篇都有。不得把神话作用、占验或古代医学说法变成现实操作指南，不要求哲学术语或标准答案。
- **验收结论分别给。** 故事可读、原典关联、合集覆盖和读者实际理解分开记录；自审不能证明真实儿童已理解，也不能证明一篇涵盖全书。用完整原文与具体故事段落关闭问题，不按引用数量、文本增长或模型自评分数宣称通过。

## 批量修订与停止

先逐篇辨认类型、目标和具体问题，分为保留、局部补足、重构主要经历、待核实来源或调整承载声明。不同类型中选择尚未验证方法的代表样篇；已成立的篇章不为整齐而重写，神话样篇通过不等于论说、兵法或医学也通过。

按本轮实际委托推进；用户保留方向确认时先确认，已授权批次不逐篇重复求审。集中处理明确缺陷，复查受影响内容与合集关系后收束；不要以“还可更有深意”无限追加改稿。改动中心目标、原典解释、受众或重要设定时，先说明相对既有合同的变化；本规则不自行授权全库重构或生产发布。
